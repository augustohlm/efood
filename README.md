# efood

Projeto de estudo desenvolvido com base no layout efood do Figma.

## Tecnologias

- React
- TypeScript
- Vite
- Styled Components
- React Router

## Primeira etapa

- Home com seis restaurantes.
- Perfil com banner e seis produtos.
- Navegação entre páginas.
- Layout adaptado para diferentes tamanhos de tela.

Os dados são demonstrativos. Os botões de compra estão desabilitados
nesta etapa; modal, carrinho e checkout serão desenvolvidos posteriormente.

## Executar localmente

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run lint
npm run build
```
